# Shreya & Rohan — Engagement Invitation

A small static invitation website. No build step or framework required.

## Preview locally
Open `index.html` in a browser, or run:
```bash
python3 -m http.server 8000
```
Then visit http://localhost:8000.

## Deploy to Vercel
1. Create a new Git repository and add all files in this folder.
2. Import the repository in Vercel.
3. Keep **Framework Preset: Other**.
4. Set **Build Command** to empty / none and **Output Directory** to `.`.
5. Deploy.

You can also drag this folder into a Vercel-compatible static deployment workflow.

The invitation artwork is used as supplied. The outer envelope is navy, with a lemon-print liner and a decorative stamp. Clicking the envelope opens the card with an animation; the Narmada Residency area and the button open the supplied Google Maps link.
